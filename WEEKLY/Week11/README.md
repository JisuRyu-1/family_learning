- **주제**: 이순신은 어떻게 열세를 뒤집었을까? (임진왜란과 거북선, 명량해전)

  20) - 초6 1,080~1,560자 / 중3 1,920~2,640자 / 성인 2,200~3,250자
- **선정 이유**: Week 03(세종대왕, 15세기 조선 전기)과 다른 시대(16세기 말 임진왜란)를
  다뤄 시즌 내 다양성을 확보. "명량해전은 거북선 덕분"이라는 대중적 통념을 사료에
  근거해 반박하는 구조라, Week 10(계절은 거리 때문이 아니다)과 같은 "통념 vs 실제 원인"
  비판적 읽기 패턴을 이어감. "하나의 원인이 아니라 여러 요인이 겹친 결과"라는 틀에서
  Week 10과 자연스럽게 연결됨.
