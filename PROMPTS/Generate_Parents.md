# Prompt: 성인(부모) 수준 비문학 생성

## 사용 시점

주간 학습 사이클 2단계 "수준별 비문학 생성" — 성인/부모용.

## 프롬프트 템플릿

```
이번 주 주제: {주제} (시즌: {시즌명}, 주차: Week {NN})
참고 소스: {CURRICULUM/시즌명.md의 "주요 소스" 참고}

위 소스들을 참고해 핵심 사실·최신 맥락·다양한 관점을 확인한 뒤, 원문을
그대로 옮기지 말고 내용을 재구성해서 성인이 읽을 비문학 지문을 새로
작성해줘. 자녀(초6/중3)에게 이번 주 내용을 설명해줄 수 있는
배경지식을 갖추는 것이 목적이다.

조건:
- 분량: {글자수 범위} (초기 2개월은 1,700~2,500자, 이후 분기마다 상향)
- 초6/중3 지문보다 깊은 배경, 최신 맥락, 다양한 관점을 포함
- 이전 주제({이전 주제})와의 연결을 명시적으로 설명
- 자녀와 대화할 때 활용할 수 있는 "좋은 질문 던지는 법" 힌트 1~2개 포함
  (정답을 주기보다 질문하는 방향)

출력 형식:
1. 제목
2. 본문
3. 자녀와의 대화를 위한 질문 힌트 1~2개
```
