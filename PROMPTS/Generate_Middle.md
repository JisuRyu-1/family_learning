# Prompt: 중3 수준 비문학 생성

## 사용 시점

주간 학습 사이클 2단계 "수준별 비문학 생성" — 중학교 3학년용.

## 프롬프트 템플릿

```
이번 주 주제: {주제} (시즌: {시즌명}, 주차: Week {NN})
참고 소스: {CURRICULUM/시즌명.md의 "주요 소스" 참고}

위 소스들을 참고해 핵심 사실과 관점을 확인한 뒤, 원문을 그대로 옮기지
말고 내용을 재구성해서 중학교 3학년이 읽을 비문학 지문을 새로 작성해줘.

조건:
- 분량: {글자수 범위} (Week 09부터 1,920~2,640자, 이후 분기마다 상향 — 이력은 [GUIDE.md](../GUIDE.md#난이도-성장) 참고)
- 원인과 결과, 비교, 주장과 근거 구조가 드러나도록 작성
- 어려운 개념/용어는 본문 아래 "단어 설명" 섹션에 정리
- 다양한 관점이 있는 주제라면 최소 2개 관점을 균형 있게 제시
- 이전 주제({이전 주제})와의 연결 지점을 한 문장으로 언급
- 마지막에 "생각해보기" 질문 2개 포함 (하나는 근거를 묻는 질문)

출력 형식:
1. 제목
2. 본문
3. 단어 설명 (5~7개)
4. 생각해보기 질문 2개
```
