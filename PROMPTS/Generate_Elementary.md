# Prompt: 초6 수준 비문학 생성

> **Note**: 2026-07-18 기준 초4 → 초6으로 대상 학년 상향. Week 01~02는
> 이미 초4 기준으로 생성되어 있으며, **Week 03부터** 아래 초6 기준을
> 적용한다.

## 사용 시점

주간 학습 사이클 2단계 "수준별 비문학 생성" — 초등 6학년용.

## 프롬프트 템플릿

```
이번 주 주제: {주제} (시즌: {시즌명}, 주차: Week {NN})
참고 소스: {CURRICULUM/시즌명.md의 "주요 소스" 참고 — 예: 우리역사넷, 국가기록원, EBS}

위 소스들을 참고해 핵심 사실을 확인한 뒤, 원문을 그대로 옮기지 말고
내용을 재구성해서 초등학교 6학년이 읽을 비문학 지문을 새로 작성해줘.

조건:
- 분량: {글자수 범위} (초기 2개월은 700~1,000자, 이후 분기마다 상향)
- 어려운 단어는 본문 아래 "단어 설명" 섹션에 쉬운 말로 풀어줄 것
- 문장은 짧고 명확하게, 흥미를 유발하는 도입부로 시작
- 마지막에 "생각해보기" 질문 1개 포함
- 이전 주제({이전 주제})와 자연스럽게 연결되는 지점이 있다면 한 문장으로 언급

출력 형식:
1. 제목
2. 본문
3. 단어 설명 (3~5개)
4. 생각해보기 질문 1개
```
