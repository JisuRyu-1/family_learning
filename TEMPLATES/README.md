4종 레이아웃 템플릿이 들어갈 폴더.

- Elementary.pdf — 초4용 레이아웃
- Middle.pdf — 중3용 레이아웃

> 폴더에 실제 .pdf(또는 원본 편집 파일)를 채워 넣으면 된다.
