# Family Learning OS

가족이 함께 성장하는 AI 기반 평생학습 시스템.

## 목적

시험 점수가 아니라 **문해력(Literacy)**을 기르는 것이 목표다. 문해력은
정보를 이해하고, 핵심을 요약하며, 비판적으로 사고하고, 자신의 언어로
설명하고, 새로운 지식을 기존 지식과 연결하는 능력이다. AI는 교사가
아니라 가족의 학습 파트너로 활용한다.
